## Почему LLM плохо считают буквы

Вопрос «сколько букв „р“ в слове „пересмотреть“?» модель видит не буквы, а токены. Буквы внутри токена для неё не видны напрямую — только id токена:

- наш BPE (bpe_16k): `пер` · `ес` · `мот` · `реть` → id [6023, 421, 2001, 11366]
- GPT-2: `�` · `�` · `е` · `р` · `е` · `с` · `м` · `о` · `т` · `р` · `е` · `т` · `ь` → id [140, 123, 16843, 21169, 16843, 21727, 43108, 15166, 20375, 21169, 16843, 20375, 45367]
- GPT-4: `п` · `ер` · `ес` · `мотр` · `ет` · `ь` → id [8164, 7753, 23297, 98397, 8341, 4929]
- GPT-4o: `пер` · `ес` · `мотреть` → id [56562, 2115, 49821]
- Qwen2.5: `пер` · `ес` · `мотр` · `еть` → id [124818, 22484, 97297, 125274]
